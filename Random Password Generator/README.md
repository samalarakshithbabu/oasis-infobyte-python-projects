# 🔐 Secure Password Creation Suite

**Author:** Samal Rakshith Babu  
**Project:** Original Password Generation Tools

A comprehensive collection of password creation utilities featuring multiple interfaces and advanced security options.

## 🚀 Available Tools

### 📟 CLI Password Creator (`password_generator_basic.py`)
- Interactive command-line password generation
- Customizable length (6-128 characters)
- Multiple character type selection
- Security-focused display options
- Input validation and error handling
- User-friendly emoji interface

### 🖥️ Secure Password Forge (`secure_password_forge.py`)
- Modern GUI with advanced features
- Character diversity enforcement
- Security strength analysis
- Ambiguous character avoidance
- Custom character exclusion
- Clipboard integration with fallback
- Real-time strength evaluation

### ⚡ Quick Password Maker (`password_generator.py`)
- Simplified GUI for rapid generation
- Essential character type controls
- Streamlined interface design
- One-click clipboard copying

## 🛠️ Installation & Setup

1. **Download Project Files**
   ```bash
   # Navigate to project directory
   cd "Random Password Generator"
   ```

2. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

## 🏃 Quick Start Guide

### CLI Password Creator
```bash
python password_generator_basic.py
```

### Secure Password Forge (Advanced GUI)
```bash
python secure_password_forge.py
```

### Quick Password Maker (Simple GUI)
```bash
python password_generator.py
```
