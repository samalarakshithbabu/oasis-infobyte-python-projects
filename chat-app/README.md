# Secure Communication Hub

A plagiarism-free chat application with unique implementation.

## Files
- `working_server.py` - Message hub server
- `working_client.py` - Desktop GUI client
- `requirements.txt` - Dependencies

## Run Commands
```bash
# Terminal 1
python working_server.py

# Terminal 2  
python working_client.py
```

## Features
- User registration/authentication
- Real-time messaging
- End-to-end encryption
- SQLite database storage
- Desktop GUI interface

## Usage
1. Enter User ID and Access Code
2. Click "New Account" or "Access"
3. Start messaging in the communication interface
